# Carvalima SAC Monitoria

Aplicação React/Vite para monitoria do SAC Carvalima.

## Publicação

Este projeto está preparado para ser importado diretamente no Vercel a partir de um repositório GitHub.

## Estrutura

- `index.html` — entrada da aplicação
- `src/main.jsx` — inicialização do React
- `src/App.jsx` — aplicação completa
- `vite.config.js` — configuração do Vite
- `package.json` — dependências e scripts

O layout utiliza Tailwind CSS via CDN para preservar as classes Tailwind já presentes no código original.
